## 게임 소개

### 게임 컨셉
이 게임은 2019년 3월에 출시한 "BABA IS YOU"의 모작 프로젝트로, 게임 내 오브젝트를 움직여 직접 규칙을 만들고 클리어 조건을 달성하는 퍼즐 게임입니다.

### 주요 특징
- **특징 1**: 독특하고 정교한 규칙 시스템

### 게임 플레이

**조작 방법**
- WASD: 캐릭터 이동

---

## 구현 내용

### 1. 게임 프레임워크
- **게임의 진행을 담당하는 프레임워크**
  - 게임에 사용되는 오브젝트들을 카탈로그 형식으로 관리 (필요 시 복제 후 사용)
  - 맵 정보를 불러와 세팅하기
  - 120fps로 랜더링하기
  - 승리 조건 파악 후, 게임 종료하기

### 2. 캐릭터 시스템
- **오브젝트별 개별 움직임 적용**
  - 싱글톤으로 플레이어 관리
  - 움직일 수 있는 오브젝트에 개별 움직임 적용
  - 생성된 규칙에 맞게 재귀적으로 경로의 모든 오브젝트의 움직임 여부를 판단

### 3. 오브젝트 시스템
- **오브젝트 구조 정의 및 규칙 적용**
  - 오브젝트의 특성에 따라 타입 분리
  - 규칙의 적용을 받는 오브젝트의 규칙 적용

### 4. 규칙 시스템
- **오브젝트 배치 구조 파악 및 규칙 생성과 적용**
  - 오브젝트의 배치에 따른 실시간 규칙 생성
  - 생성한 규칙의 내용에 따라 오브젝트에 적용

### 5. 최적화
- 더블 버퍼링 기법을 통한 끊김 없는 자연스러운 렌더링
